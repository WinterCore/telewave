# تصميم تيلي ويف — النسخة العربية

نسخة عربية كاملة من `ui-design-v2` لصفحتي **التسجيلات** و**البث المباشر**،
مبنية باستخدام Svelte 5 وTailwind CSS 4، بتخطيط من اليمين إلى اليسار.

هذا نموذج تجريبي: التشغيل والتنقّل داخل التسجيل والبث المباشر كلها محاكاة
تعتمد على الذاكرة والوقت. لا يوجد صوت فعلي أو اتصال بخادم.

## التشغيل

من جذر المستودع:

```sh
cd ui-designv2-ar
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```sh
npm run build
npm run preview
```

## التعريب

- لغة المستند عربية واتجاهه من اليمين إلى اليسار.
- النصوص والعناوين والفلاتر وتسميات قارئ الشاشة عربية، مع الحفاظ على معرّف القناة.
- الأرقام عربية والتواريخ ميلادية بأسماء أشهر عربية.
- الخط IBM Plex Sans Arabic، مع خط Tahoma بديلًا عند تعذّر تحميل خط الويب.
- تظهر العناوين كلمةً كلمةً للحفاظ على اتصال الحروف العربية.
- يبدأ شريط التقدّم من اليمين. السهم الأيسر يقدّم التشغيل عشر ثوانٍ،
  والسهم الأيمن يعيده عشر ثوانٍ، ومفتاحا Home وEnd ينتقلان للبداية والنهاية.
- البحث يتجاهل التشكيل والتطويل واختلافات الألف والياء الشائعة.
- معرّف القناة والأوقات معزولة باتجاه من اليسار إلى اليمين لحماية ترتيب الرموز.

## البنية

- `src/lib/channel.js` — هوية القناة وألوانها وخطوطها والتسجيلات التجريبية.
- `src/lib/format.js` — تنسيق الأرقام والتواريخ والأوقات والبحث العربي.
- `src/lib/stores/` — حالة التنقّل ومشغّل التسجيلات والبث التجريبي.
- `src/lib/components/` — مكوّنات الواجهة المشتركة.
- `src/lib/components/effects/` — الخلفية المتدرّجة وتأثير ظهور الكلمات.
- `src/pages/` — صفحتا التسجيلات والبث المباشر.
- `src/assets/artwork/` — الرسوم الأصلية بصيغة SVG.
